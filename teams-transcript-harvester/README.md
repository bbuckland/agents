# Teams Transcript Harvester 🤖

Automated daily extraction of Microsoft Teams meeting transcripts into your Obsidian vault. No API approvals needed - uses browser automation to access transcripts through the Teams web interface.

## Features

- **Daily automation** - Cron job runs every morning at 8 AM
- **Duplicate detection** - Tracks processed meetings to avoid re-processing
- **Obsidian integration** - Formats transcripts as proper markdown notes
- **Participant extraction** - Identifies and lists meeting participants  
- **Transcript formatting** - Clean, readable format with speakers and timestamps
- **Error recovery** - Handles login timeouts and UI changes gracefully
- **Dry run mode** - Test without saving files

## How It Works

1. **Browser Automation**: Uses Puppeteer to control Chrome/Chromium
2. **Teams Login**: Uses your existing browser session (manual login)
3. **Recording Discovery**: Scans your Teams meeting recordings
4. **Transcript Extraction**: Downloads transcript text via DOM parsing
5. **Obsidian Integration**: Saves as formatted markdown in your vault
6. **State Tracking**: Remembers processed meetings to avoid duplicates

## Installation

### Quick Setup

```bash
cd teams-transcript-harvester
chmod +x setup.sh
./setup.sh
```

### Manual Setup

```bash
# Install dependencies
npm install

# Set up Obsidian vault directory
mkdir -p ~/obsidian-vault/Meetings/Teams

# Edit configuration
cp config.env.example config.env
nano config.env

# Test run
npm run test
```

## Configuration

Edit `config.env`:

```bash
# Path to your Obsidian vault (REQUIRED)
OBSIDIAN_VAULT=/path/to/your/obsidian-vault

# Browser settings
HEADLESS=true           # Set to false for debugging
LOGIN_TIMEOUT=300       # Login timeout (5 minutes)
LOG_LEVEL=info         # Logging level
```

## Output Format

Each meeting is saved as a markdown file in your Obsidian vault:

```
📁 obsidian-vault/
└── 📁 Meetings/
    └── 📁 Teams/
        ├── 2026-02-01-Project-Kickoff.md
        ├── 2026-02-01-Weekly-Standup.md
        └── 2026-02-02-Client-Review.md
```

### Example Meeting Note

```markdown
# Project Kickoff Meeting

**Date:** 2026-02-01
**Extracted:** 2026-02-01T16:30:00.000Z
**Participants:** Bradley Buckland, Alice Johnson, Bob Smith
**Duration:** 45 transcript entries

## Key Points
<!-- Add manual notes here -->

## Action Items
<!-- Extract from transcript -->

## Full Transcript

**Bradley Buckland** (09:00): Welcome everyone, let's start with introductions...

**Alice Johnson** (09:02): Thanks Bradley. I'm Alice, leading the design team...

**Bob Smith** (09:04): Hi all, I'm Bob from engineering...

---
*Auto-generated by Teams Transcript Harvester*
```

## Troubleshooting

### Login Issues
```bash
# Run with visible browser for debugging
HEADLESS=false node harvester.js --dry-run

# Check if Teams session expired
# → Manual login required
```

### No Transcripts Found
- Verify meetings have transcription enabled in Teams
- Check if recordings are available in your Teams account
- Some meetings may not have auto-transcription

### Cron Job Not Running
```bash
# Check cron service
systemctl status cron

# View cron logs
grep CRON /var/log/syslog

# Test cron command manually
cd /opt/teams-harvester && source config.env && node harvester.js
```

### Puppeteer Issues
```bash
# Install Chrome/Chromium
apt-get update && apt-get install -y chromium-browser

# Or use Puppeteer bundled Chromium
npm install puppeteer --force
```

## Security Considerations

### What This Script Does
- ✅ Uses your existing Teams web login (no stored credentials)
- ✅ Only accesses data already available to you
- ✅ Saves transcripts locally in your Obsidian vault
- ✅ No API calls or third-party services

### What This Script Doesn't Do
- ❌ Store your Teams password or tokens
- ❌ Access data you don't already have permission to see
- ❌ Send data to external services
- ❌ Require IT approval or special API access

### Corporate Policy
This tool operates within the same security boundary as manually downloading transcripts through the Teams web interface. However, check your organization's automation policies before deployment.

## Advanced Usage

### Custom Formatting
Edit the `formatMeetingNote()` function to customize output:

```javascript
formatMeetingNote(meeting, transcriptData) {
  // Add custom frontmatter for Obsidian
  let content = `---\n`;
  content += `type: meeting\n`;
  content += `date: ${meeting.date}\n`;
  content += `participants: [${transcriptData.participants.join(', ')}]\n`;
  content += `---\n\n`;
  
  // ... rest of formatting
}
```

### Integration with OpenClaw
The generated markdown files work seamlessly with OpenClaw's memory search:

```bash
# Files are automatically indexed for semantic search
memory_search "decisions from last week's kickoff meeting"
```

### Multiple Vaults
Run multiple instances for different vaults:

```bash
# Work vault
OBSIDIAN_VAULT=/path/to/work-vault node harvester.js

# Personal vault  
OBSIDIAN_VAULT=/path/to/personal-vault node harvester.js
```
